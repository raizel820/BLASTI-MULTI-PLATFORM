BLASTI Desktop Fixes

One-click patcher for the Windows desktop app (stuck loading screen fix)
Latest: v0.3.4 ⬇ Download BLASTI-fix-0.3.4.ps1 (947 KB)

This is the only file you need. It is a PowerShell script — the extension is .ps1 (P, S, then the number one — not “psi”). It applies every fix automatically: main.js, loading-screen.js, local API, Prisma pack hook, builder config, and bumps the version to 0.3.4.

How to use

  1. Download the file above into your BLASTI-MULTI root folder (the one containing apps, packages, package.json).
  2. Open PowerShell in that folder.
  3. Run: powershell -ExecutionPolicy Bypass -File .\BLASTI-fix-0.3.4.ps1
  4. Rebuild: bun run build:desktop
  5. Start apps\desktop\dist\win-unpacked\BLASTI.exe
